5. Box Model

Every HTML element can be treated as a box. The box consists of four areas:

  • Content
  • Padding
  • Border
  • Margin
.box-model-example { width: 200px; padding: 20px; border: 5px solid black; margin: 20px; }

6. Spacing

Padding creates space inside an element. Margin creates space outside an element.

.spacing-example { margin: 30px; padding: 20px; }

7. Sizing

The width and height properties control the dimensions of an element.

.sizing-example { width: 300px; height: 100px; }
Width: 300px
Height: 100px

Minimum and Maximum Size

8. Display

The display property controls how an element participates in the page layout.

Block

.display-block { display: block; }
Block element

Inline

.display-inline { display: inline; }
Inline element

Inline-block

.display-inline-block { display: inline-block; width: 150px; }
Inline-block element

None

.hidden { display: none; }

display: none removes the element from the page layout.
