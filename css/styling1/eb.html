9. Positioning

The position property controls how an element is positioned on the page.

Relative + Absolute

An absolutely positioned element is positioned relative to its nearest positioned ancestor.

.position-container { position: relative; } .position-example { position: absolute; top: 20px; right: 20px; }
Positioned box

Fixed

A fixed element stays in the same position relative to the browser window when the page is scrolled.

.help { position: fixed; bottom: 20px; right: 20px; }

Sticky

A sticky element behaves normally until it reaches a specified position.

.header { position: sticky; top: 0; }

10. Overflow

Overflow controls what happens when content does not fit inside an element.

Auto

.overflow-example { width: 250px; height: 80px; overflow: auto; }
This is a long piece of text inside a small box. The content does not fit within the specified height, so a scrollbar appears because overflow is set to auto.

Other Values

overflow: visible; overflow: hidden; overflow: scroll; overflow: auto;

11. Visibility

The visibility property controls whether an element is visible.

Visible

.box { visibility: visible; }

Hidden

.box { visibility: hidden; }

visibility: hidden hides the element but keeps its space in the layout.

This text is hidden.

Visibility vs Display

/* Hides the element but keeps its space */ .box { visibility: hidden; } /* Hides the element and removes its space */ .box { display: none; }
