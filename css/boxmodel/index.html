CSS Box Model
The CSS Box Model describes how the browser calculates the size and spacing of every HTML element. It has 4 parts
  1. Content Box
  2. Padding Box
  3. Border Box
  4. Margin Box

CSS Box Model Properties
Part Main CSS Properties
Content width, height
Padding padding, padding-top, padding-right, padding-bottom, padding-left
Border border, border-width, border-style, border-color, border-radius
Margin margin, margin-top, margin-right, margin-bottom, margin-left
Box Sizing box-sizing
CSS box-sizing property values
Value Meaning
content-box Width and height apply only to the content. Padding and border are added outside.
border-box Width and height include content, padding, and border.
inherit Inherits the value from the parent element.
initial Resets to the default value: content-box.
unset Resets the property to its inherited or initial value.
