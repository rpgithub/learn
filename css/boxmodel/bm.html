5. Box Model

Every HTML element can be treated as a box. The box consists of four areas:

  • Content
  • Padding
  • Border
  • Margin
CSS Box Model
The CSS Box Model describes how the browser calculates the size and spacing of every HTML element. It has 4 parts
  1. Content Box
  2. Padding Box
  3. Border Box
  4. Margin Box

CSS Box Model Properties
Part Main CSS Properties
Content width, height
Padding padding, padding-top, padding-right, padding-bottom, padding-left
Border border, border-width, border-style, border-color, border-radius
Margin margin, margin-top, margin-right, margin-bottom, margin-left
Box Sizing box-sizing
CSS box-sizing property values
Value Meaning
content-box Width and height apply only to the content. Padding and border are added outside.
border-box Width and height include content, padding, and border.
inherit Inherits the value from the parent element.
initial Resets to the default value: content-box.
unset Resets the property to its inherited or initial value.

Spacing

CSS provides two main properties for controlling space around an element:

  • padding — space inside the element
  • margin — space outside the element
.spacing-example { margin: 30px; padding: 20px; }
This element has 20px padding and 30px margin.

Sizing

The width and height properties control the size of an element.

.sizing-example { width: 300px; height: 100px; }
Width: 300px
Height: 100px

You can also control minimum and maximum sizes:

.box { width: 100%; min-width: 200px; max-width: 600px; }

Display

The display property controls how an element participates in the page layout.

Block

.display-block { display: block; }
Block element

Inline

.display-inline { display: inline; }
Inline element

Inline-block

.display-inline-block { display: inline-block; width: 150px; }
Inline-block element

None

.hidden { display: none; }

display: none removes the element from the page layout.
