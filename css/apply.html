Apply styles to CSS tags

  1. Inline Styles: Put styles directly in the HTML element using style attribute
    Example:

    <span style="color: red; font-size: 20px;">
    This text is red and 20px size
    </span>
  2. External Styles: Put styles in a separate CSS file and link it to the HTML file
    Example: <link rel='stylesheet' href='common.css'/>
  3. Targeting from external: We can target html elements using ID, Class or Tag name from external CSS file.
