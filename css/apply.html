CSS Fundamentals
There are two parts to styling HTML elements using CSS.
  1. Writing CSS Rules
  2. Applying CSS Rules to html elements
Writing CSS Rules
A CSS rule comprises of three parts: Selector, Property and Value. A rule defines how a specific HTML element should be styled.
  • Selector: A selector is used to target HTML elements for styling , a selector can target HTML elements using ID, Class or Tag name.
    Example: Style using ID selector
    #t1 { color: red; font-size: 20px; }
    This will target the HTML element with id='t1' and apply the styles defined in the rule. Style using Class selector
    Example: .bbox { color: red; font-size: 20px; }
    This will target all HTML elements with class='bbox' and apply the styles defined in the rule.
    Example: p { color: red; font-size: 20px; }
    This will target all HTML elements with tag name 'p' and apply the styles defined in the rule.
  • Property: It is a style attribute of the HTML element
  • Value: It is the value of the property
Defining rules
Rules can be defined in three ways: Inline, Internal and External.
  1. Inline Styles: Put styles rules directly in the HTML element using style attribute
    Example:

    <span style="color: red; font-size: 20px;">
    This text is red and 20px size
    </span>
  2. Internal Styles: Put styles in the head section of the HTML file
    Example:

    <head>
    <style>
    span { color: red; font-size: 20px; }
    </style>
    </head>
    <body>
    <span>This text is red and 20px size</span>
    </body>
  3. External Styles: Put styles in a separate CSS file and link it to the HTML file
    Example: Add this line in the head section of HTML file to link the external CSS file:

    <link rel='stylesheet' href='common.css'/>
  4. Targeting from external: We can target html elements using ID, Class or Tag name from external CSS file.
