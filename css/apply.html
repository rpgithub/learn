CSS Fundamentals
Writing CSS Rules

A CSS rule consists of three main parts: Selector, Property, and Value.

Selector

A selector is used to target HTML elements that you want to style.

  • ID selector — targets an element by its ID
  • Class selector — targets elements by their class
  • Tag selector — targets elements by their tag name

Example: ID Selector

#t1 { color: red; font-size: 20px; }

This targets the HTML element with id="t1" and applies the specified styles.

Example: Class Selector

.bbox { color: red; font-size: 20px; }

This targets all HTML elements that have class="bbox".

Example: Tag Selector

p { color: red; font-size: 20px; }

This targets all <p> elements on the page.

Property

A property specifies the aspect of an HTML element that you want to change.

  • color
  • font-size
  • background-color
  • margin
  • padding

For example:

color: red;

color is the property.

Value

A value specifies what you want the property to be set to.

color: red;

red is the value of the color property.

Property and Value Together

font-size: 20px;
  • font-size → Property
  • 20px → Value
Applying CSS Rules

CSS rules can be added to HTML in three ways:

  1. Inline CSS
  2. Internal CSS
  3. External CSS

Inline CSS

With inline CSS, the styles are written directly inside an HTML element using the style attribute.

<span style="color: red; font-size: 20px;"> This text is red and 20px in size. </span>

Internal CSS

With internal CSS, CSS rules are placed inside a <style> element in the <head> section.

<head> <style> span { color: red; font-size: 20px; } </style> </head>

External CSS

With external CSS, CSS rules are placed in a separate CSS file.

/* common.css */ span { color: red; font-size: 20px; }

The CSS file is then linked to the HTML document:

<head> <link rel="stylesheet" href="common.css"> </head>
