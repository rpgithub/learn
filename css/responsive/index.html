1. Relative Units

%, rem, em, vw, and vh can adapt better than fixed pixels in many situations.

rem and percent

rem is based on the root font size; % is relative to a containing value.

CSS

html { font-size:16px; } .title { font-size:2rem; } .container { width:90%; }

HTML

<h1 class="title">Heading</h1><div class="container">Content</div>

2. Viewport Units

vw is based on viewport width and vh on viewport height.

Viewport-sized hero

Use vh when a section should occupy a proportion of the screen height.

CSS

.hero { min-height:70vh; padding:5vw; }

HTML

<section class="hero">Hero</section>

3. Media Queries

Media queries apply CSS only when a condition matches.

Change layout

At 768px or below, the navigation becomes a column.

CSS

@media (max-width:768px) { .nav { flex-direction:column; } }

HTML

<nav class="nav">Navigation</nav>

4. Breakpoints

A breakpoint is where the content needs a layout change. Choose breakpoints based on the design, not just device names.

Two breakpoints

The card layout changes as available width decreases.

CSS

@media (max-width:900px){ .cards{grid-template-columns:1fr 1fr;} } @media (max-width:600px){ .cards{grid-template-columns:1fr;} }

HTML

<section class="cards">Cards</section>

5. Mobile-first Design

Start with the small-screen layout, then enhance it for larger screens using min-width queries.

Mobile first

The default is one column; larger screens get two columns.

CSS

.cards { display:grid; grid-template-columns:1fr; } @media (min-width:768px){ .cards{grid-template-columns:1fr 1fr;} }

HTML

<section class="cards">Cards</section>

6. Fluid Layouts

Fluid layouts combine percentages, max-widths, and flexible functions so content scales smoothly.

Fluid content

The content shrinks on small screens but stops growing after 1200px.

CSS

.content { width:90%; max-width:1200px; margin:0 auto; } h1 { font-size:clamp(2rem,5vw,4rem); }

HTML

<main class="content"><h1>Responsive heading</h1></main>

7. Responsive Images

max-width:100% prevents an image from becoming wider than its container.

Responsive image

height:auto preserves the image's aspect ratio.

CSS

img { max-width:100%; height:auto; }

HTML

<img src="image.jpg" alt="Landscape">
