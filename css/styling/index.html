A. Basic Styling

These properties control the basic visual appearance of HTML elements.

↑ Top

1. Colors

color changes text; background-color changes the element's background.

Text and background

Use both properties to create contrast.

CSS

.message { color: white; background-color: blue; padding: 10px; }

HTML

<p class="message">Hello!</p>

Result

↑ Top

2. Typography

Typography controls font family, size, weight, style, alignment, line spacing, letter spacing, and decoration.

Text appearance

These properties change how the heading looks.

CSS

h1 { font-family: Georgia; font-size: 28px; font-weight: bold; text-align: center; }

HTML

<h1>Welcome</h1>

Result

↑ Top

3. Backgrounds

Backgrounds can be colors, images, or gradients. Size and position control image fitting.

Background image

cover fills the box and may crop the image.

CSS

.hero { width: 300px; height: 120px; background-image: url("image.jpg"); background-size: cover; background-position: center; }

HTML

<div class="hero"></div>

Result

Gradient

A gradient creates a smooth visual transition.

CSS

.banner { background: linear-gradient(to right, white, lightblue); }

HTML

<div class="banner">Banner</div>

Result

↑ Top

4. Borders

Borders surround an element. You can set width, style, color, and rounded corners.

Border and radius

border-radius rounds the corners.

CSS

.card { border: 2px solid black; border-radius: 10px; padding: 15px; }

HTML

<div class="card">Card</div>

Result

B. Box & Dimensions

This group explains the space an HTML element occupies and how its dimensions are controlled.

↑ Top

5. Box Model

The box model is content → padding → border → margin. It explains the space occupied by an element.

Complete box

The CSS creates content space, inner padding, a border, and outer margin.

CSS

.box { width: 200px; padding: 20px; border: 5px solid black; margin: 20px; }

HTML

<div class="box">Content</div>

Result

↑ Top

6. Spacing

Padding is inside the border; margin is outside the border.

Inside vs outside

Use padding for breathing room inside a component and margin to separate components.

CSS

.card { padding: 20px; margin: 30px; }

HTML

<div class="card">Card content</div>

Result

↑ Top

7. Sizing

width and height set dimensions; min/max constraints prevent elements from becoming too small or too large.

Responsive width

max-width keeps the content readable while width allows it to shrink.

CSS

.content { width: 100%; max-width: 700px; }

HTML

<main class="content">Page content</main>

Result

↑ Top

8. Display

display controls how an element participates in layout. Common values include block, inline, inline-block, flex, grid, and none.

Inline block

inline-block lets an element sit inline while still accepting width, height, and box spacing.

CSS

.button { display: inline-block; padding: 10px; }

HTML

<a class="button" href="#">Click me</a>

Result

Remove from layout

display:none hides the element and removes it from normal layout.

CSS

.hidden { display: none; }

HTML

<div class="hidden">Hidden</div>

Result

C. Element Behavior

These properties control placement, overflow, and visibility.

↑ Top

9. Positioning

Positioning changes where an element is placed. relative establishes a reference for absolute children; fixed attaches an element to the viewport; sticky sticks during scrolling.

Absolute inside relative

The badge is positioned relative to the container.

CSS

.container { position: relative; } .badge { position: absolute; top: 10px; right: 10px; }

HTML

<div class="container"><span class="badge">New</span></div>

Result

Fixed

A fixed element stays attached to the viewport.

CSS

.help { position: fixed; right: 20px; bottom: 20px; }

HTML

<button class="help">Help</button>

Result

Sticky

A sticky element behaves normally until it reaches the specified offset.

CSS

.header { position: sticky; top: 0; }

HTML

<header class="header">Header</header>

Result

↑ Top

10. Overflow

overflow controls content that is larger than its box. auto adds scrolling only when needed.

Scrollable box

Useful for fixed-height areas containing unpredictable amounts of content.

CSS

.box { width: 200px; height: 80px; overflow: auto; }

HTML

<div class="box">A lot of content...</div>

Result

↑ Top

11. Visibility

visibility:hidden hides the element but preserves its layout space. display:none removes it from normal layout.

Hidden but keeps space

Useful when an element may become visible later.

CSS

.hidden { visibility: hidden; }

HTML

<p class="hidden">Hidden text</p>

Result

Removed

The element no longer takes normal layout space.

CSS

.removed { display: none; }

HTML

<p class="removed">Removed</p>

Result

12. Lists

list-style-type controls bullets and numbering.

Custom bullets

Change the marker style of a list.

CSS

ul { list-style-type: square; }

HTML

<ul><li>One</li><li>Two</li></ul>

13. Tables

Table styling improves readability using borders, padding, alignment, and spacing.

Table borders

border-collapse makes adjacent borders behave as a single border.

CSS

table { border-collapse: collapse; } th, td { border: 1px solid #999; padding: 8px; }

HTML

<table><tr><th>Name</th></tr><tr><td>John</td></tr></table>

Result

↑ Top

14. Images

object-fit controls how an image fits inside a fixed box.

Cropping an image

cover fills the box while maintaining the image's aspect ratio.

CSS

img { width: 300px; height: 200px; object-fit: cover; }

HTML

<img src="image.jpg" alt="Landscape">

Result

15. Shadows & Effects

box-shadow adds depth to boxes; opacity makes an element partially transparent.

Box shadow

Creates visual depth around a component.

CSS

.card { box-shadow: 0 4px 12px rgba(0,0,0,.2); }

HTML

<div class="card">Card</div>

Result

Opacity

Makes the whole element and its contents more transparent.

CSS

.muted { opacity: .6; }

HTML

<p class="muted">Secondary text</p>

Result

16. Pseudo-classes

Pseudo-classes select elements based on state or position, such as hover, focus, active, or first-child.

Hover and focus

Style a button when the pointer is over it and an input when it receives focus.

CSS

button:hover { background: lightblue; } input:focus { outline: 2px solid blue; }

HTML

<button>Hover me</button> <input placeholder="Focus me">

Result

↑ Top

17. Pseudo-elements

Pseudo-elements style part of an element or generate content before or after it.

Generated label

::before inserts generated content before the element's real content.

CSS

.note::before { content: "Note: "; font-weight: bold; }

HTML

<p class="note">Read carefully.</p>

Result

↑ Top

18. Transitions

Transitions smoothly animate a property change between two states.

Smooth hover

The transform changes smoothly over 0.3 seconds.

CSS

button { transition: transform .3s; } button:hover { transform: scale(1.05); }

HTML

<button>Hover me</button>

Result

↑ Top

19. Transforms

Transforms visually move, rotate, scale, or skew an element without changing normal document flow.

Move and rotate

The element moves and rotates when hovered.

CSS

.box:hover { transform: translateX(20px) rotate(5deg); }

HTML

<div class="box">Hover me</div>

Result

↑ Top

20. Animations

Animations use @keyframes to define stages of movement or visual change.

Keyframe animation

The element moves from its starting position to a new position repeatedly.

CSS

@keyframes slide { from { transform: translateX(0); } to { transform: translateX(100px); } } .box { animation: slide 2s infinite alternate; }

HTML

<div class="box">Animated</div>

Result
