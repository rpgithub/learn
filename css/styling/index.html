A. Basic Styling

1. Colors

The color property changes the text color. The background-color property changes the background color.

.color-example { color: white; background-color: blue; }

White text with a blue background.

2. Typography

Typography controls the appearance and presentation of text.

.typography-example { font-family: Georgia, serif; font-size: 24px; font-weight: bold; font-style: italic; text-align: center; line-height: 1.5; letter-spacing: 2px; text-decoration: underline; }

This is a typography example.

3. Backgrounds

Background properties control the background color or image of an element.

.background-color-example { background-color: lightblue; }
This box has a light blue background.
.background-image-example { width: 300px; height: 120px; background-image: url("image.jpg"); background-repeat: no-repeat; background-size: cover; background-position: center; }

4. Borders

Borders are drawn around an element.

.border-example { border: 2px solid black; border-radius: 10px; }
Black border with rounded corners.
.solid-border { border: 2px solid black; } .dashed-border { border: 2px dashed black; } .dotted-border { border: 2px dotted black; }

B. Box & Dimensions

5. Box Model

Every HTML element can be treated as a box consisting of content, padding, border, and margin.

.box-model-example { width: 200px; padding: 20px; border: 5px solid black; margin: 20px; }
Content

6. Spacing

Padding creates space inside an element. Margin creates space outside an element.

.spacing-example { margin: 30px; padding: 20px; }
Content with margin and padding.

7. Sizing

The width and height properties control the dimensions of an element.

.sizing-example { width: 300px; height: 100px; }
300px × 100px

8. Display

The display property controls how an element participates in the page layout.

.display-block { display: block; } .display-inline { display: inline; } .display-inline-block { display: inline-block; width: 150px; }

C. Element Behavior

9. Positioning

Positioning allows you to control the location of an element.

.container { position: relative; } .box { position: absolute; top: 20px; right: 20px; }
Positioned box

10. Overflow

Overflow controls what happens when content does not fit inside an element.

.overflow-example { width: 250px; height: 80px; overflow: auto; }
This is a long piece of text inside a small box. The content does not fit within the specified height, so a scrollbar appears because overflow is set to auto.

11. Visibility

visibility: hidden hides an element while keeping its space in the layout.

.visibility-hidden { visibility: hidden; }

D. Component Styling

12. Lists

List properties control the appearance of ordered and unordered lists.

.list-example { list-style-type: square; } .list-example li { margin-bottom: 8px; }

13. Tables

CSS can control table borders, spacing, alignment, and other visual properties.

.table-example { border-collapse: collapse; } .table-example th, .table-example td { border: 1px solid black; padding: 10px; }

14. Images

The object-fit property controls how an image fits inside its defined dimensions.

.image-example { width: 300px; height: 150px; object-fit: cover; }

15. Shadows & Effects

The box-shadow property adds a shadow around an element.

.shadow-example { width: 200px; padding: 20px; box-shadow: 0 4px 10px gray; }
This box has a shadow.

E. Interactive Styling

16. Pseudo-classes

Pseudo-classes style an element based on its state.

.hover-button:hover { background-color: blue; color: white; }

17. Pseudo-elements

Pseudo-elements style a specific part of an element or insert generated content.

.pseudo-example::before { content: "★ "; }

This text has content added before it.

18. Transitions

Transitions make changes between CSS states happen smoothly.

.transition-button { transition: background-color 0.3s; } .transition-button:hover { background-color: green; color: white; }

19. Transforms

Transforms can move, resize, rotate, or skew an element.

.transform-example { transition: transform 0.3s; } .transform-example:hover { transform: scale(1.2); }
Hover over me

20. Animations

Animations allow an element to change through multiple stages automatically.

.animation-example { animation: move 2s infinite alternate; } @keyframes move { from { transform: translateX(0); } to { transform: translateX(200px); } }
