Layout and Positioning
Layout and positioning are important concepts in CSS that allow you to control the placement and arrangement of elements on a web page. There are several techniques and properties available in CSS to achieve different layout and positioning effects.
CSS Layout Techniques
display property controls the layout type of an element and how it participates in the page layout. Its possible values include: block, inline, inline-block, flex, grid, none, etc. Each value has its own behavior and use cases.
Display Value Explanation Common Use Cases
block Starts on a new line and generally takes the available width. Sections, divs, paragraphs, headings
inline Stays within the current line and takes only the space it needs. Text, links, spans
inline-block Stays on the same line but allows width and height to be set. Buttons, badges, labels
flex Creates a Flexbox container for arranging its direct children. Navigation bars, rows, columns, alignment
inline-flex Creates a Flexbox container that behaves like an inline element. Small inline groups of UI elements
grid Creates a Grid container for arranging children in rows and columns. Page layouts, card layouts, dashboards
inline-grid Creates a Grid container that behaves like an inline element. Small inline grid layouts
none Removes the element from the page layout and makes it invisible. Hiding elements, conditional UI
Flexbox is a CSS layout system for arranging, aligning, and distributing elements in a row or column.
  • Arrange items horizontally or vertically
  • Align items
  • Distribute available space
  • Add consistent spacing between items
  • Create responsive layouts
CSS Grid is a CSS layout system used to arrange elements in rows and columns.

Flexbox vs Grid

  • Flexbox → primarily one-dimensional: row or column
  • Grid → two-dimensional: rows and columns
