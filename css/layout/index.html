1. Flexbox

Flexbox is primarily one-dimensional: a row or a column.

Start Flexbox

Set display:flex on the parent. Its direct children become flex items.

CSS

.nav { display: flex; }

HTML

<nav class="nav"><a>Home</a><a>About</a></nav>

Result

2. Flex Container

The flex container controls how its direct children are laid out.

Parent and children

Only the direct children become flex items.

CSS

.container { display: flex; border: 1px solid black; }

HTML

<div class="container"><div>One</div><div>Two</div></div>

Result

↑ Top

3. Flex Direction

flex-direction defines the main axis.

Column layout

column stacks the items vertically.

CSS

.menu { display:flex; flex-direction:column; }

HTML

<div class="menu"><div>One</div><div>Two</div></div>

Result

4. Justify & Align

justify-content works along the main axis; align-items works along the cross axis.

Centering

Together these properties can center content in both axes when the container has enough height.

CSS

.container { display:flex; justify-content:center; align-items:center; height:150px; }

HTML

<div class="container"><div>Centered</div></div>

Result

5. Gap

gap creates consistent space between flex or grid items.

Spacing items

Use gap instead of adding a separate margin to every item.

CSS

.container { display:flex; gap:20px; }

HTML

<div class="container"><div>One</div><div>Two</div></div>

Result

↑ Top

6. Flex Wrap

flex-wrap lets items move to additional lines when necessary.

Wrapping cards

Useful for flexible collections of items.

CSS

.cards { display:flex; flex-wrap:wrap; gap:10px; }

HTML

<div class="cards"><div>1</div><div>2</div><div>3</div></div>

7. Flex Items

flex, order, and align-self control individual flex items.

Flexible item

flex:1 allows an item to grow and share available space.

CSS

.item { flex: 1 1 200px; }

HTML

<div class="item">Flexible item</div>

8. CSS Grid

Grid is two-dimensional, giving you control over rows and columns.

Three columns

repeat creates three equal columns.

CSS

.cards { display:grid; grid-template-columns:repeat(3,1fr); gap:20px; }

HTML

<section class="cards"><div>1</div><div>2</div><div>3</div></section>

Result

↑ Top

9. Grid Rows & Columns

Grid lines let an item span selected columns or rows.

Wide item

The item spans the first two columns.

CSS

.featured { grid-column:1 / 3; }

HTML

<div class="featured">Wide card</div>

10. Grid Gap

gap, row-gap, and column-gap control spacing between grid tracks.

Different gaps

Use separate row and column spacing when needed.

CSS

.grid { display:grid; grid-template-columns:1fr 1fr; row-gap:10px; column-gap:20px; }

HTML

<div class="grid"><div>1</div><div>2</div></div>

Result

11. Grid Areas

Named areas make complex page layouts easier to read.

Page structure

HTML elements are assigned to meaningful named regions.

CSS

.page { display:grid; grid-template-areas:"header header" "sidebar main"; } header { grid-area:header; } aside { grid-area:sidebar; } main { grid-area:main; }

HTML

<div class="page"><header>Header</header><aside>Sidebar</aside><main>Main</main></div>

12. Common Layout Patterns

Use Flexbox for navigation and one-dimensional alignment; use Grid for cards, dashboards, and two-dimensional page structure.

Navigation + cards

Real pages often use both systems together.

CSS

.nav { display:flex; justify-content:space-between; } .cards { display:grid; grid-template-columns:repeat(3,1fr); }

HTML

<nav class="nav">Logo <span>Links</span></nav> <section class="cards">Cards</section>
