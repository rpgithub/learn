1. CSS Variables

Custom properties store reusable values and are accessed with var().

Reusable value

Define a value once and reuse it across components.

CSS

:root { --primary:blue; --spacing:16px; } button { background:var(--primary); padding:var(--spacing); }

HTML

<button>Save</button>

2. calc()

calc() combines compatible CSS values to create flexible dimensions.

Calculated width

Subtract fixed space from a flexible percentage.

CSS

.content { width:calc(100% - 40px); margin:0 20px; }

HTML

<main class="content">Content</main>

3. clamp()

clamp(min, preferred, max) lets a value grow within safe limits.

Fluid typography

The heading grows with the viewport but stays between 2rem and 4rem.

CSS

h1 { font-size:clamp(2rem,5vw,4rem); }

HTML

<h1>Responsive heading</h1>

4. min() / max() / minmax()

These functions make dimensions flexible. min() and max() choose values; minmax() is especially useful in Grid.

Flexible limits

Keep content within 1000px while allowing it to shrink.

CSS

.content { width:min(90%,1000px); } .grid { display:grid; grid-template-columns:repeat(3,minmax(150px,1fr)); }

HTML

<main class="content">Content</main><section class="grid">Cards</section>

5. z-index

z-index controls stacking order when elements overlap, usually with positioned elements.

Modal above page

A large z-index places the dialog above lower stacking layers.

CSS

.modal { position:fixed; z-index:1000; }

HTML

<div class="modal">Dialog</div>

6. Advanced Selectors

Modern selectors such as :is(), :where(), :not(), :has(), and attribute selectors express more precise relationships.

Useful selectors

These selectors reduce extra classes and can describe element relationships.

CSS

input[type="email"] { ... } .card :is(h2,h3) { ... } button:not(.secondary) { ... } .card:has(img) { ... }

HTML

<div class="card"><img src="image.jpg" alt="Example"><h2>Card</h2></div>

7. Practical Theming

CSS variables make themes and design-system changes easier because shared values can be changed in one place.

Theme variables

Components reference shared design values instead of hard-coding them.

CSS

:root { --bg:white; --text:#222; --accent:blue; } .page { background:var(--bg); color:var(--text); } .button { background:var(--accent); }

HTML

<div class="page"><button class="button">Action</button></div>
