1. Selectors

Selectors choose the HTML elements to which a CSS rule applies.

Element selector

What it does: Targets HTML elements by their tag name.
Common / important values:
  • `p`, `h1`, `div`, `button`
Complete reference: MDN reference ↗

Targets every element of a particular HTML tag.

CSS

p { color: blue; }

HTML

<p>Hello CSS</p>

Result

Class selector

What it does: Targets elements that have a particular class.
Common / important values:
  • `.class-name`
Complete reference: MDN reference ↗

Targets elements with a reusable class name.

CSS

.highlight { color: red; }

HTML

<p class="highlight">Important</p>

Result

ID selector

What it does: Targets one element using its `id`.
Common / important values:
  • `#id-name`
Complete reference: MDN reference ↗

Targets an element with a specific ID.

CSS

#header { background-color: lightgray; }

HTML

<header id="header">Header</header>

Result

Descendant / child selectors

A descendant can be anywhere inside an ancestor; > means a direct child.

CSS

.card p { color: gray; } nav > a { text-decoration: none; }

HTML

<div class="card"><p>Text</p></div> <nav><a href="#">Home</a></nav>

Result

2. Properties & Values

A property says what to change; its value says how to change it.

Basic declaration

Multiple declarations can style one HTML element.

CSS

p { color: blue; font-size: 20px; margin: 10px; }

HTML

<p>Hello CSS</p>

3. Cascade

When several rules apply, the cascade determines which declaration is used. With equal priority and specificity, the later rule wins.

Source order

The second rule wins here because both selectors are identical.

CSS

p { color: blue; } p { color: green; }

HTML

<p>This becomes green.</p>

4. Specificity

Specificity gives selectors different weights when rules compete. IDs are generally more specific than classes, which are more specific than element selectors.

Specificity comparison

The ID selector wins over the class and element selectors.

CSS

p { color: blue; } .note { color: green; } #warning { color: red; }

HTML

<p class="note" id="warning">Warning</p>

5. Inheritance

Some properties, especially text-related ones, are inherited from a parent by its children.

Inherited text styles

The paragraph inherits color and font-family from body.

CSS

body { color: #333; font-family: Arial; }

HTML

<body><p>This inherits the styles.</p></body>
